# Freight Invoice Automation

## Project Overview
Freight Invoice Automation is a system designed to automate the processing of freight invoices received from different carriers, customs brokers, and warehouses.

## Problem Statement
Freight invoices come in different PDF formats and layouts. Manually extracting invoice details and reconciling them with booking records is time-consuming and can lead to errors.

## Objectives
- Extract important information from freight invoice PDFs.
- Reconcile extracted details with existing booking records.
- Generate invoice drafts for review.
- Flag low-confidence or mismatched invoices for human approval.
- Provide a dashboard to track invoice status, processing time, and error rates.

## Planned Workflow
PDF Upload → Data Extraction → Booking Reconciliation → Invoice Draft → Human Review (if required) → Dashboard

## Current Progress
- Reviewed the project requirements.
- Collected sample freight invoice PDFs from DHL.
- Began exploring invoice layout variations for testing.
